# HealthMonitor — дизайн-концепция интерфейса

## Идея: «прикроватный монитор на миллиметровке»
Платформа — инструмент наблюдения, а не маркетинговый SaaS. Визуальный язык берётся из клинического мира:
прикроватный монитор (крупные цифры жизненных показателей, приоритеты тревог) и регистрационная бумага ЭКГ
(сетка под графиками). Всё остальное — тихое: светлая «бумага», тонкие линейки, плотная, но читаемая типографика.

Самое заметное — показатели. Цифры набраны крупно и с моноширинными цифрами (tabular-nums), остальное уступает им.

## Токены
| Роль | Светлая | Тёмная |
|---|---|---|
| Бумага (фон) | `#EEF2F0` | `#0E191B` |
| Лист (панель) | `#FFFFFF` | `#142225` |
| Чернила (текст) | `#17262A` | `#E2EBE9` |
| Приглушённый текст | `#56676B` | `#93A7A6` |
| Линейка (границы) | `#D3DDDA` | `#29403F` |

Красный **не используется** для декора и кнопок — только для тревог высокого приоритета.

### Приоритеты тревог (по мотивам IEC 60601-1-8)
Состояние кодируется **формой и текстом**, не только цветом (доступность для дальтоников, ч/б печать):
| Приоритет | Знак | Цвет |
|---|---|---|
| Критический (высокий) | ▲ треугольник | `#C62A1F` |
| Отклонение (средний) | ◆ ромб | заливка `#E0A100`, текст `#8A5A00` |
| Нет данных (низкий) | ○ кольцо | `#1B7FA6` |
| Норма | без знака | приглушённый зелёный текст `#2F7553` |

## Типографика
Golos Text (Paratype, создан для российских госсервисов — полная кириллица), локально через `@fontsource`.
Шкала: 13 / 15 (база) / 17 / 22 / 28; показатели монитора — 34–40. Заголовки без ALL CAPS и без «бровок».

## Сетка и ритм
Отступы кратны 4 (4/8/12/16/24/32). Радиусы различаются по иерархии: элементы управления 6px, панели 10px.
Панели разделяются линейками, а не тенями; тень — только у всплывающих слоёв (уведомления, диалоги).

## По ролям
- **Врач**: сверху — очередь тревог, ожидающих реакции, с таймером относительно SLA 15 мин и кнопкой «Принять»;
  ниже — сводка отделения одной строкой и «палатная доска» пациентов (приоритет, последние значения, время, быстрые действия).
- **Пациент**: «монитор» последних показателей рядом с формой ввода; ниже — динамика на сетке ЭКГ, врач и отклонения.
- **Родственник**: явная метка «Только просмотр» в шапке и пояснение, что действия недоступны.
- **Администратор**: постоянная пометка «без доступа к медицинским данным»; таблицы на телефоне раскладываются в карточки.

## Общие компоненты
`Panel/Card`, `Mark` (знак приоритета), `SeverityBadge`, `Stat`, `Readout`, `LineChart` (сетка ЭКГ), `Field`,
`Segmented`, `Tabs`, `Dialog` (подтверждение/ввод, вместо `window.confirm/prompt`), `Notice`, `Empty`, `Spinner/Loadable`.

## Доступность
Контраст текста ≥ 4.5:1 в обеих темах; видимый фокус (`:focus-visible`, 2px акцентный контур); ссылка «Перейти к
содержанию»; мобильное меню — выезжающая панель с подложкой, закрывается Esc; диалоги удерживают фокус и
возвращают его; `prefers-reduced-motion` отключает анимации.
